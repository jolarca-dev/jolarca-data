# Translation memory — domain glossary pairs lt/lv/et/en

Preferred term pairs for marketplace domain vocabulary, consumed by
listing translation quality checks and `ai_service_app` multilingual
search.

- `glossary.csv` — the committed term pairs (see below).
- **Legal terms are not owned here.** Canonical legal glossary lives in
  `jolarca-legal/docs/glossary.md`; legal terms in this file sync FROM
  there (never the reverse) and are marked `source=jolarca-legal`.

## Rules

1. One canonical pair per concept; synonyms are recorded, conflicts
   are resolved by the marketplace product owner.
2. Changes to legal-term rows require the jolarca-legal sync to land
   first (they are evidence of legal drafting).
3. Charset is UTF-8 with full diacritics (ą č ę ė į š ų ū ž / ā č ē ģ
   ī ķ ļ ņ š ū ž / ä ö õ ü š ž) — transliteration is a defect.
